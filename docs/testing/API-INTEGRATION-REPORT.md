| Route ID | Path Predicate | Target Microservice | URL Mapping |
|---|---|---|---|
| `identity-service` | `/api/v1/auth/**`, `/api/v1/users/**` | `identity-service` | `http://localhost:8081` |

## 2. Correlation ID Propagation
- **Header**: `X-Correlation-ID`
- **Behavior**: Passed by client or automatically generated by API Gateway if omitted. Downstream microservices log `X-Correlation-ID` and attach it to Kafka event envelopes. Tested with header `TEST-INTEGRATION-001`.

---

## 3. Response Structure Standardization
All 12 microservices adhere to unified JSON response envelopes:

### Success Response Format:
```json
{
  "success": true,
  "message": "Operation completed successfully",
  "data": { ... },
  "timestamp": "2026-09-29T10:00:00Z"
}
```

### Error Response Format:
```json
{
  "success": false,
  "message": "Resource not found",
  "errorCode": "NOT_FOUND",
  "timestamp": "2026-09-29T10:00:00Z",
  "path": "/api/v1/catalog/products/invalid-id",
  "correlationId": "TEST-INTEGRATION-001"
}
```
